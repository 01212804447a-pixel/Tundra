# Tundra — дальномер по карте для War Thunder

Программа показывает **расстояние (в метрах) и азимут** от вашей техники до цели,
которую вы отметили на карте в War Thunder.

## Что умеет

* **Клик по карте в окне программы** — указываете цель мышью и получаете дистанцию,
  азимут и квадрат сетки (`2360 м, азимут 41° (СВ), квадрат D8`). Работает всегда,
  даже если игра не отдаёт метку.
* **Метка на карте игры** — если игра передаёт её в `map_obj.json`, расстояние
  считается автоматически.
* **Засвеченные враги** — расстояние до ближайших видимых на карте противников.
* **Точки захвата** — расстояние до A, B, C…

Какая цель главная (большие цифры вверху окна): клик → метка → ближайший враг.

## Как это работает

Во время боя War Thunder поднимает локальный веб-сервер
`http://127.0.0.1:8111` (его же использует браузерная карта игры). Программа
два раза в секунду читает оттуда:

* `map_info.json` — реальные размеры текущей карты в метрах (`map_min`, `map_max`)
  и шаг сетки;
* `map_obj.json` — объекты мини-карты в координатах 0…1: ваша техника
  (`icon: "Player"`), союзники, враги, точки захвата.

Сторона определяется по цвету значка (стандартная палитра): вы — жёлтый `#faC81E`,
взвод — зелёный `#67D756`, союзники — синие (`#174DFF` и оттенки), враги — красный
`#fa0C00`. При включённом режиме для дальтоников цвета другие, и врагов программа
может не распознать.

Дистанция = `√((Δx·ширина_карты)² + (Δy·высота_карты)²)`.
Азимут: 0° — верх карты (север), 90° — восток, по часовой стрелке.

Программа **ничего не меняет в игре и ничего в неё не встраивает**. Она только
читает официальный локальный API, как обычная браузерная карта на порту 8111.

## Установка

Нужен Python 3.8+ (на Windows при установке отметьте «tcl/tk and IDLE»).
Сторонние библиотеки не нужны. Если установить `pip install pillow`, под сеткой
будет показываться картинка самой карты (`map.img`).

```bash
git clone <repo> && cd Tundra
python wt_rangefinder.py
```

## Использование

1. Запустите программу — появится окно с картой поверх всех окон.
   Чтобы оно было видно поверх игры, включите в игре режим
   **«Оконный без рамки»** (или «В окне»).
2. В бою **кликните ЛКМ** по цели на карте в окне программы
   (ориентируйтесь по сетке и квадратам: они такие же, как в игре)
   или поставьте метку на карте в игре.
3. Вверху окна появится дистанция до цели. **ПКМ** сбрасывает выбранную точку,
   **Ctrl+M** скрывает карту, и остаётся только дальномер.

Параметры:

| Ключ | Описание |
|------|----------|
| `--console` | выводить в консоль вместо окна |
| `--once` | один замер и выход |
| `--interval 0.5` | период обновления, сек |
| `--alpha 0.9` | прозрачность окна (0.2–1.0) |
| `--map-size 420` | размер карты в окне, пикселей |
| `--host http://127.0.0.1:8111` | адрес API (например, если игра на другом ПК в сети) |

## Проверка без игры

```bash
python fake_wt_server.py          # имитация API игры на порту 8111
python wt_rangefinder.py          # в другом терминале
python -m unittest discover -s tests -v
```

## Ограничения

* Считается **горизонтальная** дистанция по карте; перепад высот API не отдаёт.
* Точность зависит от того, насколько точно поставлена метка: на больших картах
  одна точка мини-карты — это несколько метров.
* Пока неизвестно, отдаёт ли игра метку игрока в `map_obj.json`: в дампе из
  реального боя без метки её нет. Клик по карте в окне работает независимо от этого.
* В режиме «Полноэкранный» Windows не даёт окнам перекрывать игру — используйте
  консольный режим на втором мониторе или оконный режим игры.
